# Algeri_Khmaladze_grouped_data
Code and data needed to replicate the results in Algeri and  Khmaladze (2026)  https://arxiv.org/abs/2406.09195 

\begin{itemize}
\item  File \texttt{Chandra\_data.txt:}   contains the  data from the Chandra $X$-ray observatory described in Section 1.1. 
\item  File \texttt{Chandra\_analysis.R:}   contains the  \texttt{R} code used to conduct the analysis of the data from Chandra and discussed in Sections 4.1, 6.3.1, 7.1.1, and to reproduce Figure 1. 
\item  File \texttt{Example\_I.R:}    contains the \texttt{R} code used for the power simulation for Example I described  in Section 6.2 and to generate the left panel of Figure 2. 
\item  File \texttt{Example\_II.R:}    contains the \texttt{R} code used for the power simulation for Example II described  in Section 6.2 and to generate the central panel of Figure 2. 
\item  File \texttt{Example\_III.R:}    contains the \texttt{R} code used for the power simulation for Example III described  in Section 6.2 and to generate the right panel of Figure 2. 
\item  File \texttt{Example\_IV.R:}    contains the \texttt{R} code used for the power simulation for Example IV described in Sections 6.4 and  7.1. 
\item  File \texttt{Fig3.R:}  contains the  \texttt{R} code used  to generate  the left panel of Figure 3  in which the null distribution of the  $\widehat{\text{KS}}$ and  $\overbar{\text{KS}}$  statistics  are compared.
\item  File  \texttt{Numerical\_study\_Sec\_7\_2.R:} contains the    \texttt{R} code used to compare the CPU time required by the projected parametric bootstrap and the classical parametric bootstrap as described in Section 7.2. 
 \item  File  \texttt{Sec\_7\_3\_correction\_term.R:} contains the  \texttt{R} code used to derive the  $\frac{0.6}{\sqrt{K}}$ shift for the $\text{KS}^*$  statistic   as described in Section 7.3.
 \item   File \texttt{Fig4.R:} contains the    \texttt{R} code used to generate the plots in Figure 4 in which the simulated null distribution of the  $\overbar{\text{KS}}$  
and  $\text{KS}^*$  statistics  are compared with the Kolmogorov distribution when testing  different models.
\end{itemize}
