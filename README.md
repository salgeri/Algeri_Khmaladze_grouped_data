Code and data needed to replicate the results in **Algeri and Khmaladze, *On the statistical analysis of grouped data: when Pearson χ² and other divisible statistics are not goodness-of-fit tests*, Journal of the Royal Statistical Society B (2026)**
[https://arxiv.org/abs/2406.09195](https://arxiv.org/abs/2406.09195)

---

## File Descriptions

- **`Chandra_data.txt`** — Data from the Chandra X-ray observatory described in Section 1.1.

- **`Chandra_analysis.R`** — R code for the analysis of the Chandra data discussed in Sections 4.1, 6.3.1, and 7.1.1, and to reproduce Figure 1.

- **`Example_I.R`** — R code for the power simulation for Example I described in Section 6.2, and to generate the left panel of Figure 2.

- **`Example_II.R`** — R code for the power simulation for Example II described in Section 6.2, and to generate the central panel of Figure 2.

- **`Example_III.R`** — R code for the power simulation for Example III described in Section 6.2, and to generate the right panel of Figure 2.

- **`Example_IV.R`** — R code for the power simulation for Example IV described in Sections 6.4 and 7.1.

- **`Fig3.R`** — R code to generate the left panel of Figure 3, in which the null distributions of the $\widehat{\text{KS}}$ and $\overline{\text{KS}}$ statistics are compared.

- **`Numerical_study_Sec_7_2.R`** — R code to compare the CPU time required by the projected parametric bootstrap and the classical parametric bootstrap, as described in Section 7.2.

- **`Sec_7_3_correction_term.R`** — R code to derive the $\frac{0.6}{\sqrt{K}}$ shift for the $\text{KS}^*$ statistic, as described in Section 7.3.

- **`Fig4.R`** — R code to generate the plots in Figure 4, in which the simulated null distributions of the $\overline{\text{KS}}$ and $\text{KS}^*$ statistics are compared with the Kolmogorov distribution when testing different models.
